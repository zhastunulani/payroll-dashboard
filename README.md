# Айлық дашборды

Компанияның ай сайынғы айлық қорын, қызметкерлер төлемін және операциялық
шығындарын бір жерден бақылауға арналған жабық веб-қосымша.

Интерфейс қазақ тілінде жасалған. Әр есептік ай жеке snapshot ретінде
сақталады, сондықтан кейінгі өзгерістер бұрынғы айлардың статистикасын
өзгертпейді.

## Негізгі мүмкіндіктер

- жоспарланған, төленген және қалған сомаларды көрсететін дашборд;
- өткен аймен сомалық және пайыздық салыстыру;
- бөлімдер, қызметкерлер, лауазымдар және төлем түрлерін басқару;
- негізгі айлыққа қосымша төлемдер мен ұсталымдарды есептеу;
- `ПС` компонентін айлыққа қосу;
- шығындар мен олардың төлем статусын жүргізу;
- жаңа айды preview арқылы құрып, қызметкерлер мен айлықтарды көшіру;
- дашбордтан бір реттік шығынды атауы мен сомасы арқылы жылдам тіркеу және
  бөлек «Басқа шығындар» реестрінде жүргізу;
- таңдалған бөлімге Excel немесе CSV арқылы қызметкерлерді жаппай импорттау;
- бір ортақ парольмен қорғалған беттер мен қаржылық API.

## Технологиялар

- Next.js 16, React 19 және TypeScript;
- Neon Serverless Postgres;
- Cloudflare-мен үйлесімді `@neondatabase/serverless` HTTP драйвері;
- Cloudflare Workers Free және `@opennextjs/cloudflare`;
- Render Web Service тек резервтік deployment ретінде сақталған;
- PBKDF2 арқылы хэштелген ортақ пароль;
- `HttpOnly`, `SameSite=Strict`, production-да `Secure` сессия cookie-і.

## Жергілікті іске қосу

Қажетті нұсқалар:

- Node.js `22.22.0` немесе `package.json` файлының `engines` талабына сай
  Node.js 22;
- npm;
- бос Neon Postgres жобасы.

Алдымен тәуелділіктерді орнатыңыз:

```powershell
npm ci
Copy-Item .env.example .env.local
```

`.env.local` файлын нақты құпия мәндермен толтырыңыз:

```dotenv
DATABASE_URL=postgresql://user:password@host-pooler.example/database?sslmode=require
APP_PASSWORD_HASH=pbkdf2.100000.salt.hash
SESSION_SECRET=кемінде-32-таңбадан-тұратын-кездейсоқ-құпия
```

Айнымалылар:

- `DATABASE_URL` — Neon Dashboard ішіндегі **Connect** батырмасынан алынған
  pooled connection string. Pooled endpoint хостында әдетте `-pooler` болады;
- `APP_PASSWORD_HASH` — алғашқы кіруге арналған ортақ парольдің PBKDF2 хэші;
- `SESSION_SECRET` — сессияға қол қоюға арналған кемінде 32 таңбалық кездейсоқ
  құпия.

Қарапайым парольді `.env.local` файлына жазбаңыз. PowerShell-де парольді
экранда көрсетпей хэш жасауға болады:

```powershell
$securePassword = Read-Host "Ортақ пароль" -AsSecureString
$plainPassword = [Net.NetworkCredential]::new("", $securePassword).Password
$env:PAYROLL_PASSWORD = $plainPassword
npm run hash-password
Remove-Item Env:PAYROLL_PASSWORD
Remove-Variable plainPassword, securePassword
```

Шыққан хэшті `APP_PASSWORD_HASH` мәніне қойыңыз. Қосымшаны іске қосыңыз:

```powershell
npm run dev
```

Сайт `http://localhost:3000` мекенжайында ашылады. Алғашқы сұраныста қажетті
Postgres кестелері мен бастапқы анықтамалықтар автоматты түрде құрылады.

## Neon базасын дайындау

1. Neon Dashboard-та жеке жоба мен негізгі branch құрыңыз.
2. **Connect** терезесінен pooled connection string көшіріңіз.
3. Connection string ішінде TLS параметрі (`sslmode=require`) бар екенін
   тексеріңіз.
4. Мәнді жергілікті `.env.local` және Cloudflare-дегі құпия `DATABASE_URL`
   айнымалысына ғана сақтаңыз.
5. Қосымшаны іске қосып, `/api/health` endpoint-і
   `{"status":"ok"}` қайтаратынын тексеріңіз.

Қосымша бірінші іске қосылғанда схеманы өзі дайындайды. Қызметкерлер, айлықтар,
шығындар және өзгертілген ортақ пароль Neon базасында сақталады.

## Жаңа айды ашу

Жаңа ай алдыңғы айдан Академ, Мұғалімдер, Маркетинг Eduser және Ustaz Media
қызметкерлерін негізгі айлығы, қосымша төлемдері және ұсталымдарымен бірге
көшіреді. **Кураторлар** мен **Сату бөлімі** жаңа айда әрқашан бос ашылады.
Олардың жаңа тізімі мен сол айдағы сомалары Баптаулардағы Excel импорты арқылы
енгізіледі. Өткен айдағы деректер өзгермейді.

## Бөлімге Excel немесе CSV импорттау

Қызметкер қосу және импорттау тек басқару аймағында орындалады:

1. **Баптаулар → Қызметкерлер** бетін ашыңыз.
2. **Қызметкер қосылатын бөлім** өрісінен қажетті бөлімді таңдаңыз.
3. **Excel импорт** батырмасын басып, `.xlsx` немесе `.csv` файлын таңдаңыз.
4. Алдын ала тексеру экранындағы адам санын, айлық қорын және қателерді
   тексеріңіз.
5. Қате жоқ болса, импорттауды растаңыз.

Осы бетте қызметкерлерді іздеуге, бір адамды қолмен қосуға, өзгертуге және
толық өшіруге болады. **Бөлімдер** беті тек айлық есеп пен төлем статустарын
қарауға арналған, онда қосу және импорт әрекеттері көрсетілмейді.

Қосымша Excel-дегі барлық парақты тексереді және таңдалған бөлімнің атауына
сәйкес парақты бірінші қолданады. Кесте бірінші жолдан басталмаса да,
`ФИО`/`Аты-жөні` header жолы автоматты табылады. Баған атаулары қазақша немесе
орысша болуы мүмкін:

| Дерек | Қолдау көрсетілетін баған атаулары | Міндеттілігі |
| --- | --- | --- |
| Қызметкер | `Қызметкер`, `ФИО`, `Аты-жөні`, `Сотрудник`, `Имя`; немесе бөлек `Фамилия`, `Имя`, `Отчество` | Міндетті |
| Негізгі айлық | `Негізгі айлық`, `Базалық айлық`, `Оклад` | Қосымша; бос болса `0 ₸` |
| Жалпы сома | `Жалпы сома`, `Айлық`, `Сумма`, `Итого`, `Общий зп`, `ЗП`, `Зарплата` немесе таңдалған ай атауы | Қосымша |
| Төлем түрі | `Төлем түрі`, `Төлем форматы`, `Способ оплаты`, `Оплата` | Қосымша; бос болса `Аударым` |
| Лауазым | `Лауазым`, `Должность`, `Қызметі` | Қосымша |
| Қосымша/ұсталым | `ПС`, `Бонус`, `Мат 2.2`, `Англ 1`, `Удержание` және басқа сомалық бағандар | Қосымша; қорытынды сомаға қосылады немесе шегеріледі |
| Төленді | `Төленді`, `Төленген`, `Оплачено` | Қосымша |
| Бөлім | `Бөлім`, `Отдел` | Қосымша; интерфейсте таңдалған бөлім қолданылады |

`Төленді` бағанында `true`, `1`, `иә`, `да`, `төленді`, `оплачено` немесе `+`
мәндерінің бірі қолданылса, жол төленген болып белгіленеді.

Сомалар Excel number ұяшығы немесе `1 000 ₸`, `200 000 тг`, `2 000 000`
мәтіндік форматында танылады. Бір жолдан табылған барлық сома біріктіріліп,
қызметкердің **Негізгі айлығы** ретінде сақталады. Файлда `Жалпы сома` немесе
`Итого` бағаны болса, сол дайын қорытынды қолданылады. Preview экранында
аты-жөн, негізгі айлық және жалпы қор импортқа дейін көрсетіледі.

Алдын ала тексеру:

- белгісіз бөлім мен төлем түрін;
- қате немесе теріс соманы;
- файл ішіндегі қайталанған қызметкерді көрсетеді.

Сервер бір импортта ең көбі 2000 жол қабылдайды және таңдалған айда сол бөлімде
бар қызметкерді қайта қосудан қорғайды. Импорттан кейін бөлімнің адам саны мен
айлық қоры автоматты түрде жаңарады.

## Қызметкерлерді жаппай басқару

Бөлімдегі қызметкерлер кестесінің үстінде **Барлығын таңдау** әрекеті бар.
Қалыпты режимде қызметкерлердің жанында checkbox көрсетілмейді. Осы әрекетті
басқанда таңдау режимі ашылып, барлық қызметкер белгіленеді. Кейін жалпы
checkbox-ты босатып, тек қажетті 2–3 қызметкерді жеке таңдауға болады. Таңдалған
қызметкерлерге:

- `Төленді` деп жаппай белгілеу;
- `Төленбеді` деп жаппай қайтару;
- толық өшіру әрекеті қолданылады.

Жаппай өшіру алдында міндетті растау көрсетіледі. Өшіру қызметкердің барлық
айлардағы snapshot-тары мен айлық компоненттерін де жояды және қайтарылмайды.

Операциялық **Шығындар тізімінде** де дәл осындай таңдау режимі бар.
Таңдалған шығындарды бір әрекетпен `Төленді`, `Төленбеді` деп белгілеуге немесе
толық өшіруге болады. Жұмсалып қойған бір реттік «Басқа шығындар» жазбалары бұл
операциялық жаппай әрекеттерге кірмейді.

## Бір реттік «Басқа шығындар»

Парта, орындық немесе басқа бір реттік сатып алуды тіркеу үшін:

1. **Дашборд** бетіндегі **Жаңа шығын** батырмасын басыңыз.
2. Шығын атауы мен сомасын енгізіңіз.
3. Жазбаны сақтаңыз.
4. Толық тізімді сол блоктағы **Реестрді ашу** арқылы қараңыз.

Мұндай жазбаның категориясы автоматты түрде `Басқа шығындар` болады.
Категория жүйелік болғандықтан, оны Баптаулардан өзгертуге немесе архивтеуге
болмайды. Бұл реестр жалақы төлемі емес: сақталған ақша осы айда жұмсалған факт
ретінде бірден есептеледі, сондықтан `Төленді` белгісі жоқ. Сома жалпы жоспарға
және жұмсалған сомаға кіреді де, айдың қалған сомасынан бірден шегеріледі.
Жазба операциялық шығындар тізімінде қайталанбайды және жаңа айға көшірілмейді.

## Cloudflare Workers Free-ге жариялау

Негізгі production deployment — Cloudflare Workers Free. Worker сұраныс келгенде
Cloudflare edge runtime ішінде бірден орындалады және Render Free Web Service
сияқты 15 минуттан кейін sleep режиміне өтпейді. Сол себепті UptimeRobot
keep-alive қажет емес.

Қолданылатын файлдар:

- `wrangler.jsonc` — Worker атауы, assets, compatibility және міндетті secrets;
- `open-next.config.ts` — Next.js → Cloudflare Workers адаптері;
- `scripts/cloudflare-command.mjs` — Windows-тағы кирилл жолдарына арналған
  қауіпсіз build workaround;
- `.dev.vars` — тек жергілікті preview құпиялары, Git-ке кірмейді.

Жергілікті Worker preview:

```powershell
npm run sync:worker-env
npm run build:worker
npm run preview:worker
```

Preview әдетте `http://127.0.0.1:8787` мекенжайында ашылады. Тексеріңіз:

- `/api/ping` → `200` және `{"status":"ok"}`;
- `/api/health` → `200` және Neon байланысы жұмыс істейді;
- парольсіз `/api/payroll` → `401`;
- ортақ парольмен кіргеннен кейін дашборд деректері ашылады.

Алғашқы production deployment:

```powershell
npx wrangler login --use-keyring
npx wrangler whoami
npm run deploy:worker
```

Production URL: <https://payroll-dashboard.zhastunulani.workers.dev>

`--secrets-file .env.local` үш міндетті құпияны Worker-ге шифрланған secret
ретінде жүктейді:

- `DATABASE_URL`;
- `APP_PASSWORD_HASH`;
- `SESSION_SECRET`.

Құпия мәндерді `wrangler.jsonc`, README немесе GitHub репозиторийіне
жазбаңыз. Deployment аяқталған соң Wrangler берген `*.workers.dev` URL ішінде
`/api/health`, кіру және қорғалған Payroll API тексеріледі.

Cloudflare Workers Free тарифінде UptimeRobot қажет емес. Қазіргі тегін лимит
күніне 100 000 сұраныс; платформа тарифі болашақта өзгеруі мүмкін, сондықтан
«мәңгі тегін» коммерциялық кепілдік емес, бірақ бұл архитектурада idle sleep
жоқ. Ресми мәліметтер:
[Workers pricing](https://developers.cloudflare.com/workers/platform/pricing/)
және
[Workers limits](https://developers.cloudflare.com/workers/platform/limits/).

### Render резервтік deployment

`render.yaml` ішіндегі `plan: free` өзгертілмеген. Ол резервтік нұсқа ретінде
қалады, бірақ Render Free динамикалық сервисі бос тұрған кезде sleep режиміне
өтетіндіктен негізгі always-ready URL ретінде қолданылмайды.

## Тексеру командалары

```powershell
npm run test:unit
npm run typecheck
npm run build
npm run build:worker
npm run lint

```

`npm test` есептеу логикасын, ақша форматтау мен ай ауысуын, бір реттік
шығындардың жаңа айға көшірілмеуін, `/api/ping` жауабын, Cloudflare Worker
конфигурациясын, Render резервтік Free конфигурациясын, D1-синтаксисінен
Postgres SQL-іне түрлендіруді, production build-ті және серверлік пароль
қорғанысын тексереді.

## Қауіпсіздік және Git ережелері

- `.env*` файлдары Git арқылы жіберілмейді; тек құпиясыз `.env.example`
  репозиторийде қалады.
- `.xlsx`, `.xls`, `.csv` және `.tsv` файлдары `.gitignore` ішінде.
- Қызметкерлердің аты-жөні, айлықтары, нақты қаржылық деректер және парольдер
  GitHub-та сақталмауы керек.
- Импорт файлын репозиторий папкасына көшірмей, сыртқы қауіпсіз папкадан
  таңдаңыз.
- Бизнес беттері мен `/api/payroll` ортақ пароль сессиясын талап етеді.
- `/api/health` deployment мониторингі үшін ашық, бірақ ол қаржылық дерек
  қайтармайды.
- `/api/ping` жеңіл availability тексерісі үшін ашық және дерекқорға
  қосылмайды.
- Ортақ пароль Баптаулар бетінен өзгертілгенде, жаңа хэш Neon базасына
  жазылады және барлық бұрынғы сессиялар жарамсыз болады.

## Деректерді сақтау логикасы

- ақша бүтін теңгемен сақталады;
- интерфейсте ақша `1 000 ₸`, `200 000 ₸`, `2 000 000 ₸` форматында көрсетіледі;
- қызметкер айлығы: `негізгі айлық + қосымшалар − ұсталымдар`;
- `Төленді` белгісі толық есептелген соманы төленген деп есептейді;
- төленген айлық өзгерсе, төлем белгісі алынады;
- қызметкер өшірілгенде оның барлық айдағы snapshot-тары мен айлық
