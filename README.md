# Айлық дашборды

Бөлімдердің айлық қорын, қызметкерлердің төлем статусын және операциялық
шығындарды ай сайын бақылауға арналған жабық веб-қосымша.

## Мүмкіндіктер

- айларды snapshot ретінде сақтау және алдыңғы айдан көшіру;
- бөлімдер, қызметкерлер, айлық компоненттері және төлем түрлері;
- аренда, интернет, сервистер және басқа операциялық шығындар;
- төленген және қалған сомалар, айлық салыстыру статистикасы;
- Excel/CSV арқылы қызметкерлерді импорттау;
- бір ортақ пароль және қорғалған серверлік API.

## Қауіпсіздік

Нақты қызметкерлер, айлықтар және парольдер репозиторийде сақталмайды.
`APP_PASSWORD_HASH` және `SESSION_SECRET` мәндері тек жергілікті немесе
deployment ортасының құпия айнымалыларында болуы керек.

## Жергілікті іске қосу

1. `.dev.vars.example` файлын `.dev.vars` ретінде көшіріп, нақты құпия
   мәндермен толтырыңыз.
2. `npm ci`
3. `npm run dev`

Cloudflare D1 кестелері бірінші сұраныста қауіпсіз түрде дайындалады; deployment
кезінде `drizzle` миграциялары қолданылады.
